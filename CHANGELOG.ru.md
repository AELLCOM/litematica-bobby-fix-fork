# Litematica Bobby Fix — история версий

## 1.1.7+1.21.11 (25.10.2026)

- Номер семейства 1.1.7 (как 1.1.7+26.3/+26.2; 1.1.4–1.1.7 меняли только вшитый Bobby для 26.3).
- Порт на Minecraft 1.21.11 (Fabric Loader 0.19.3, Fabric API 0.141.6, Java 21), сборка против
  Litematica 0.26.16 / malilib 0.27.20, работает с официальным Bobby 5.2.11.1+mc1.21.11.
- Код тот же, что в 1.1.3+26.2 и 1.1.7+26.3 (лечение «схема в чанках Bobby пропадала через раз»): хуки
  `bobby_onFakeChunkAdded/Removed`, `Minecraft.schedule`, `SchematicPlacementManager.onClientChunkLoad/Unload`
  в 1.21.11 на месте. У инъекций в методы `bobby_*` — `remap = false` (их добавляет миксин Bobby, имён Mojang нет).
  Bobby не вшит: в 1.21.11 есть официальный.
- Проверено на голом стенде `~/projects/_smoke-1.21.11` (`./smoke.sh <лог> bobby`, готовый jar в run/mods):
  уход на 11 чанков и обратно — 179 фейковых чанков Bobby, все 179 переданы в Litematica через Bobby Fix.

## 1.1.3+26.2 (23.09.2026)

- **Исправлено: схема в чанках Bobby пропадала примерно через раз.** Когда сервер выгружает чанк,
  Bobby подставляет фейковый прямо внутри `ClientChunkCache.drop()` — раньше, чем Litematica на
  выходе из `handleForgetLevelChunk` выгрузит свой чанк схемы. Пересборку Litematica 0.28+ ведёт
  в отдельном потоке (`PlacementManagerDaemonHandler`), и она успевала загрузить чанк схемы до этой
  выгрузки — чанк схемы исчезал до следующего настоящего чанка: схема там не рисовалась, а
  Material HUD 0.0.21 терял узоры баннеров в таких чанках (строки с узорами слипались в обычные).
  Теперь загрузка откладывается в очередь клиента (`Minecraft.schedule`) и выполняется после
  обработчика пакета; перед загрузкой проверяется, что фейковый чанк ещё на месте.
- Без изменений: выгрузка чанка схемы при удалении фейкового чанка, `require = 0` на обеих
  инъекциях (без Bobby мод ничего не делает).

## 1.1.0+26.2 (04.08.2026)

- Порт на Minecraft 26.2.
- Цель миксина записана в Mojang-именах: `net.minecraft.client.multiplayer.ClientChunkCache`
  вместо intermediary-имени `class_631` из сборки под 1.21.8.
- `compatibilityLevel` миксинов поднят до `JAVA_25`, компиляция под Java 25.
- Зависимости в `fabric.mod.json`: `minecraft ~26.2`, `fabricloader >=0.16`.
- Сборка переведена на Loom 1.17 / Gradle 9.5.1, Litematica 0.28.4 и malilib 0.29.3 под 26.2.
